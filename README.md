# Tumbleweed — Chase Rolling Loot Across Deserts

Tumbleweed 9minecraft Mod adds rolling tumbleweeds to dry biomes like deserts and savannas. These bouncing plants blow across the sand and drop random items when you break them. The mod makes empty wastelands feel more alive while giving you a fun reason to chase after moving targets for extra loot.

Rolling Loot Pinatas: Tumbleweeds drop random items like sticks, seeds, or rare treasures when broken. Spawns naturally in deserts, badlands, and savannas near dead bushes.

## What this build is

An unofficial rebuild of **konwboj**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
